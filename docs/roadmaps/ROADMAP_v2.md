# 오늘의 경제뉴스 겟 블로그 v2 개발 로드맵 — 온디맨드 캐시 무효화

운영자가 Notion DB 수정 직후 ISR 캐시 대기 없이 즉시 최신 콘텐츠를 확인할 수 있도록 온디맨드 캐시 무효화 기능을 추가하는 첫 번째 기능 개선 로드맵

> ✅ **v1(MVP) 완료 상태**: Phase 0~4 전체 완료 (T001~T020, 약 80h) — 프로덕션 배포 완료 (https://notion-cms-for-economy.vercel.app/). 상세 내역은 [`ROADMAP_v1.md`](./ROADMAP_v1.md) 참조.

## 개요

**온디맨드 캐시 무효화 기능**은 Notion CMS로 콘텐츠를 관리하는 1인 운영자를 위한 개선으로, ISR 캐시 갱신 주기(600초/3600초)를 기다리지 않고 원클릭으로 현재 페이지를 즉시 갱신하는 다음 기능을 제공합니다:

- **온디맨드 캐시 무효화 API (F012)**: 비밀 토큰 검증 후 `revalidatePath`로 지정 경로의 ISR 캐시를 즉시 무효화하는 서버 전용 Route Handler
- **최신정보 확인하기 버튼 (F013)**: 모든 페이지 우측 하단 플로팅 버튼으로 현재 경로 캐시 무효화 API를 호출하고, 토스트 피드백 후 자동 새로고침
- **4개 페이지 전면 적용**: 홈(`/`), 카테고리(`/category/[name]`), 글 상세(`/posts/[id]`), 종목(`/stocks`) 전체에 버튼 노출

## 개발 워크플로우

1. **작업 계획**
   - 기존 코드베이스를 학습하고 현재 상태를 파악
   - 새로운 작업을 포함하도록 `ROADMAP.md` 업데이트
   - 우선순위 작업은 마지막 완료된 작업 다음에 삽입

2. **작업 생성**
   - 기존 코드베이스를 학습하고 현재 상태를 파악
   - `/tasks` 디렉토리에 새 작업 파일 생성
   - 명명 형식: `XXX-description.md` (예: `021-revalidate-api.md`)
   - 고수준 명세서, 관련 파일, 수락 기준, 구현 단계 포함
   - **API/비즈니스 로직 작업 시 "## 테스트 체크리스트" 섹션 필수 포함 (Playwright MCP 테스트 시나리오 작성)**
   - 예시를 위해 `/tasks` 디렉토리의 마지막 완료된 작업 참조 (예: 현재 작업이 `023`이라면 `022`, `021` 참조)
   - 새 작업의 경우, 문서에는 빈 박스와 변경 사항 요약이 없어야 함. 초기 상태의 샘플로 `000-sample.md` 참조

3. **작업 구현**
   - 작업 파일의 명세서를 따름
   - 기능과 기능성 구현
   - **API 연동 및 비즈니스 로직 구현 시 Playwright MCP로 테스트 수행 필수**
   - 각 단계 후 작업 파일 내 단계 진행 상황 업데이트
   - 구현 완료 후 Playwright MCP를 사용한 E2E 테스트 실행
   - 테스트 통과 확인 후 다음 단계로 진행
   - 각 단계 완료 후 중단하고 추가 지시를 기다림

4. **로드맵 업데이트**
   - 로드맵에서 완료된 작업을 ✅로 표시

- **T021: 온디맨드 캐시 무효화 API Route 구현** ✅ - 완료
  - **상태**: ✅ 완료 | **기능 ID**: F012 | **예상 소요시간**: 3h
  - ✅ `src/lib/env.ts`에 `REVALIDATE_SECRET` Zod 검증 추가 (한국어 에러 메시지)
  - ✅ `src/app/actions.ts` — Server Action `revalidatePageAction` 구현 (API Route 대신 채택, secret 클라이언트 완전 미노출)
