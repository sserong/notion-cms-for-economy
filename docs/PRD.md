# 오늘의 경제뉴스 겟 블로그 MVP PRD

## 핵심 정보

**목적**: Notion을 CMS로 활용하여 경제뉴스를 수집하고, 작성한 글이 자동으로 블로그에 반영되는 개인 블로그 서비스. 뉴스 원본 링크와 관련 주식 종목 정보를 함께 제공하며, 오늘의 추천종목 페이지를 별도 운영한다.
**사용자**: 경제뉴스를 정기적으로 읽고 싶은 독자 및 Notion으로 콘텐츠를 관리하는 1인 블로거

---

## 사용자 여정

```
1. 홈 페이지 (최근 뉴스 글 목록)
   ↓ 카테고리 클릭 또는 검색어 입력

   [카테고리 선택] → 카테고리 페이지 (해당 카테고리 글 목록)
   [검색어 입력]   → 홈 페이지 (검색 결과 필터링 표시)
   [추천종목 클릭] → 오늘의 추천종목 페이지
   ↓

2. 글 목록에서 글 카드 클릭
   ↓

3. 글 상세 페이지 (본문 읽기 + 원본 뉴스 링크 + 관련 종목 확인)
   ↓ 읽기 완료 후

4. 뒤로 가기 또는 홈 버튼 클릭 → 홈 페이지
```

## 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명                 | 설명                                                                                | MVP 필수 이유                   | 관련 페이지                                      |
| -------- | ---------------------- | ----------------------------------------------------------------------------------- | ------------------------------- | ------------------------------------------------ |
| **F001** | Notion 글 목록 조회    | Notion 뉴스 DB에서 발행 상태인 글 목록을 가져와 최신순으로 표시                     | 서비스 핵심 콘텐츠 제공         | 홈 페이지                                        |
| **F002** | 글 상세 조회           | 선택한 글의 Notion 페이지 본문을 파싱하여 표시                                      | 콘텐츠 소비의 본질적 기능       | 글 상세 페이지                                   |
| **F003** | 카테고리 필터링        | Notion 뉴스 DB의 Category 필드 기준으로 글 목록 필터링                              | 독자의 관심 분야별 탐색 지원    | 홈 페이지, 카테고리 페이지                       |
| **F004** | 글 검색                | 제목 기준으로 글 목록을 실시간 필터링하여 표시                                      | 콘텐츠 탐색 편의성 제공         | 홈 페이지                                        |
| **F005** | 반응형 레이아웃        | 모바일/태블릿/데스크톱 화면 크기에 최적화된 레이아웃 제공                           | 모바일 독자 접근성 보장         | 홈 페이지, 글 상세 페이지, 카테고리 페이지, 종목 |
| **F006** | 뉴스 원본 링크 제공    | 각 경제뉴스 글에 원본 뉴스 URL 링크를 함께 표시                                     | 독자의 원본 확인 및 신뢰성 제공 | 홈 페이지 (카드), 글 상세 페이지                 |
| **F007** | 관련 주식 종목 표시    | 각 경제뉴스 글에 관련 주식 종목 최대 3개(종목명 + 종목코드)를 함께 표시             | 경제뉴스와 투자 정보 연결       | 홈 페이지 (카드), 글 상세 페이지                 |
| **F008** | 오늘의 추천종목 페이지 | Notion 종목 DB에서 활성 상태 종목을 최신순으로 조회하여 전용 페이지에 목록으로 표시 | 투자 관심 독자를 위한 핵심 기능 | 오늘의 추천종목 페이지                           |

## 데이터 모델

### Post (뉴스 데이터베이스 레코드)

| 필드          | 설명                      | 타입/관계               |
| ------------- | ------------------------- | ----------------------- |
| id            | Notion 페이지 고유 ID     | string (UUID)           |
| title         | 글 제목                   | string                  |
| category      | 카테고리 분류             | string (select)         |
| tags          | 태그 목록                 | string[] (multi_select) |
| published     | 발행일                    | Date                    |
| status        | 발행 상태 (초안/발행됨)   | string (select)         |
| newsLink      | 원본 뉴스 URL             | string \| null (url)    |
| relatedStocks | 관련 주식 종목 (최대 3개) | RelatedStock[]          |

### RelatedStock (Post에 내포된 관련 종목)

| 필드 | 설명                    | 타입/관계 |
| ---- | ----------------------- | --------- |
| name | 종목명 (예: "삼성전자") | string    |
| code | 종목코드 (예: "005930") | string    |

### Stock (종목 데이터베이스 레코드)

| 필드     | 설명                    | 타입/관계            |
| -------- | ----------------------- | -------------------- |
| id       | Notion 페이지 고유 ID   | string (UUID)        |
| name     | 종목명                  | string               |
| code     | 종목코드                | string               |
| sector   | 업종 분류               | string \| null       |
| date     | 추천일                  | Date \| null         |
| status   | 활성 상태 (활성/비활성) | string (select)      |
| reason   | 추천 이유 요약          | string \| null       |
| newsLink | 관련 뉴스 링크          | string \| null (url) |

### NotionBlock (글 본문 블록)

| 필드    | 설명                                | 타입/관계 |
| ------- | ----------------------------------- | --------- |
| id      | 블록 고유 ID                        | string    |
| type    | 블록 유형 (paragraph, heading_1 등) | string    |
| content | 블록 텍스트 내용                    | string    |
| post_id | 소속 포스트 ID                      | → Post.id |

## 기술 스택 (최신 버전)

### 프론트엔드 프레임워크

- **Next.js 15** (App Router + Turbopack) — React 풀스택 프레임워크, SSG/ISR로 Notion API 호출 최소화
- **TypeScript 5.6+** — 타입 안전성 보장
- **React 19** — UI 라이브러리 (최신 동시성 기능)

### 스타일링 & UI

- **TailwindCSS v4** (설정 파일 없는 새로운 엔진) — 유틸리티 CSS 프레임워크
- **shadcn/ui** — 고품질 React 컴포넌트 라이브러리 (Badge, Card, Input 등)
- **Lucide React** — 아이콘 라이브러리

### CMS 연동

- **@notionhq/client** — Notion 공식 API 클라이언트
- **notion-to-md** (선택) — Notion 블록을 Markdown으로 변환하는 유틸리티

### 배포 & 호스팅

- **Vercel** — Next.js 15 최적화 배포 플랫폼, 환경 변수 관리

- **npm** — 의존성 관리
