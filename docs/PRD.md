# 오늘의 경제뉴스 겟 블로그 MVP PRD

## 핵심 정보

**목적**: Notion을 CMS로 활용하여 경제뉴스를 수집하고, 작성한 글이 자동으로 블로그에 반영되는 개인 블로그 서비스
**사용자**: 경제뉴스를 정기적으로 읽고 싶은 독자 및 Notion으로 콘텐츠를 관리하는 1인 블로거

---

## 사용자 여정

```
1. 홈 페이지 (최근 글 목록)
   ↓ 카테고리 클릭 또는 검색어 입력

   [카테고리 선택] → 카테고리 페이지 (해당 카테고리 글 목록)
   [검색어 입력]   → 홈 페이지 (검색 결과 필터링 표시)
   ↓

2. 글 목록에서 글 카드 클릭
   ↓

3. 글 상세 페이지 (본문 읽기)
   ↓ 읽기 완료 후

4. 뒤로 가기 또는 홈 버튼 클릭 → 홈 페이지
```

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|--------------|------------|
| **F001** | Notion 글 목록 조회 | Notion 데이터베이스에서 발행 상태인 글 목록을 가져와 최신순으로 표시 | 서비스 핵심 콘텐츠 제공 | 홈 페이지 |
| **F002** | 글 상세 조회 | 선택한 글의 Notion 페이지 본문을 파싱하여 표시 | 콘텐츠 소비의 본질적 기능 | 글 상세 페이지 |
| **F003** | 카테고리 필터링 | Notion 데이터베이스의 Category 필드 기준으로 글 목록 필터링 | 독자의 관심 분야별 탐색 지원 | 홈 페이지, 카테고리 페이지 |
| **F004** | 글 검색 | 제목 기준으로 글 목록을 실시간 필터링하여 표시 | 콘텐츠 탐색 편의성 제공 | 홈 페이지 |
| **F005** | 반응형 레이아웃 | 모바일/태블릿/데스크톱 화면 크기에 최적화된 레이아웃 제공 | 모바일 독자 접근성 보장 | 홈 페이지, 글 상세 페이지, 카테고리 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|--------------|------------|
| **F010** | Notion API 연동 | @notionhq/client를 통한 Notion 데이터베이스 쿼리 및 페이지 콘텐츠 fetch | 모든 핵심 기능의 데이터 공급원 | 홈 페이지, 글 상세 페이지, 카테고리 페이지 |
| **F011** | Notion 블록 렌더링 | Notion 페이지의 블록 타입(paragraph, heading, image 등)을 HTML로 변환 | 본문 표시를 위한 필수 변환 | 글 상세 페이지 |

### 3. MVP 이후 기능 (제외)

- 댓글 기능
- 소셜 공유 버튼
- 뉴스레터 구독

- 페이지네이션 (초기에는 최근 N개 목록으로 대체)
- 태그 기반 필터링 (카테고리 필터링으로 대체)

## 페이지별 상세 기능

### 홈 페이지

> **구현 기능:** `F001`, `F003`, `F004`, `F005`, `F010` | **인증:** 불필요 (전체 공개)

| 항목 | 내용 |
|------|------|
| **역할** | 블로그 랜딩 페이지 — 최근 발행된 경제뉴스 글 목록을 표시하고 탐색 진입점 제공 |
| **진입 경로** | 직접 URL 접속, 로고 클릭, 글 상세 페이지에서 홈 버튼 클릭 |
| **사용자 행동** | 최근 글 목록 스캔, 카테고리 버튼으로 필터링, 검색바에 키워드 입력, 글 카드 클릭으로 상세 이동 |
| **주요 기능** | - Notion API에서 발행 상태(Status: 발행됨) 글만 최신순 조회 (F001, F010)<br>- 글 카드: 제목, 카테고리 배지, 발행일, 요약 첫 줄 표시 (F001)<br>- 카테고리 필터 버튼 목록 (전체/주식/부동산/거시경제/기업·산업) (F003)<br>- 검색바: 제목 기준 클라이언트사이드 실시간 필터링 (F004)<br>- 모바일 1열 / 태블릿 2열 / 데스크톱 3열 그리드 레이아웃 (F005) |
| **다음 이동** | 글 카드 클릭 → 글 상세 페이지, 카테고리 버튼 클릭 → 카테고리 페이지 |

---

### 글 상세 페이지

> **구현 기능:** `F002`, `F005`, `F010`, `F011` | **인증:** 불필요 (전체 공개)

| 항목 | 내용 |
|------|------|
| **역할** | 개별 경제뉴스 글의 전체 본문을 표시하는 핵심 콘텐츠 페이지 |
| **진입 경로** | 홈 페이지 또는 카테고리 페이지의 글 카드 클릭 |
| **사용자 행동** | 글 본문 읽기, 제목/카테고리/발행일 확인, 홈으로 돌아가기 |
| **주요 기능** | - Notion 페이지 ID로 페이지 블록 데이터 fetch (F002, F010)<br>- Notion 블록 타입별 렌더링: paragraph, heading_1~3, bulleted_list, numbered_list, image, code (F011)<br>- 글 메타 정보 헤더: 제목, 카테고리 배지, 발행일 표시 (F002)<br>- 본문 최대 너비 제한(max-w-2xl) 및 가독성 타이포그래피 적용 (F005)<br>- **홈으로 돌아가기** 버튼 |
| **다음 이동** | 홈으로 돌아가기 버튼 클릭 → 홈 페이지 |

---

### 카테고리 페이지

> **구현 기능:** `F003`, `F005`, `F010` | **인증:** 불필요 (전체 공개)

| 항목 | 내용 |
|------|------|
| **역할** | 특정 카테고리에 속하는 글만 필터링하여 목록으로 표시 |
| **진입 경로** | 홈 페이지 카테고리 필터 버튼 클릭, 헤더 카테고리 메뉴 클릭 |
| **사용자 행동** | 특정 카테고리 글 목록 탐색, 글 카드 클릭으로 상세 이동, 다른 카테고리 전환 |
| **주요 기능** | - Notion API에서 특정 Category 값으로 필터링된 글 목록 조회 (F003, F010)<br>- 현재 선택된 카테고리 이름 페이지 상단에 표시 (F003)<br>- 글 카드 목록: 제목, 발행일, 요약 첫 줄 표시 (F003)<br>- 다른 카테고리로 전환하는 카테고리 탭 버튼 (F003)<br>- 모바일 1열 / 태블릿 2열 / 데스크톱 3열 그리드 레이아웃 (F005) |
| **다음 이동** | 글 카드 클릭 → 글 상세 페이지, 카테고리 탭 클릭 → 해당 카테고리 페이지 |

## 데이터 모델

### Post (Notion 데이터베이스 레코드)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion 페이지 고유 ID | string (UUID) |
| title | 글 제목 | string |
| category | 카테고리 분류 | string (select) |
| tags | 태그 목록 | string[] (multi_select) |
| published | 발행일 | Date |
| status | 발행 상태 (초안/발행됨) | string (select) |

### NotionBlock (글 본문 블록)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 블록 고유 ID | string |
| type | 블록 유형 (paragraph, heading_1 등) | string |
| content | 블록 텍스트 내용 | string |
| post_id | 소속 포스트 ID | → Post.id |

## 기술 스택 (최신 버전)

### 프론트엔드 프레임워크

- **Next.js 15** (App Router + Turbopack) — React 풀스택 프레임워크, SSG/ISR로 Notion API 호출 최소화
- **TypeScript 5.6+** — 타입 안전성 보장
- **React 19** — UI 라이브러리 (최신 동시성 기능)

### 스타일링 & UI

- **TailwindCSS v4** (설정 파일 없는 새로운 엔진) — 유틸리티 CSS 프레임워크
- **shadcn/ui** — 고품질 React 컴포넌트 라이브러리 (Badge, Card, Input 등)
- **Lucide React** — 아이콘 라이브러리

### CMS 연동

- **@notionhq/client** — Notion 공식 API 클라이언트
- **notion-to-md** (선택) — Notion 블록을 Markdown으로 변환하는 유틸리티

### 배포 & 호스팅

- **Vercel** — Next.js 15 최적화 배포 플랫폼, 환경 변수 관리

### 패키지 관리

- **npm** — 의존성 관리

## Notion 데이터베이스 스키마

Notion에서 아래 구조로 데이터베이스를 생성합니다.

| 필드명 | Notion 타입 | 값 예시 |
|--------|------------|--------|
| Title | title | "2025년 한국 기준금리 전망" |
| Category | select | 주식 / 부동산 / 거시경제 / 기업·산업 |
| Tags | multi_select | 금리, 한국은행, 통화정책 |
| Published | date | 2025-05-10 |
| Status | select | 초안 / 발행됨 |

> **중요**: Notion API 통합(Integration)에서 데이터베이스 연결 권한을 부여해야 합니다.
> 환경 변수: `NOTION_API_KEY`, `NOTION_DATABASE_ID`
